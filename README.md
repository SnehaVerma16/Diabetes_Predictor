# 🩺 Diabetes Prediction System

A Machine Learning web application that predicts whether a patient is at **High Risk** or **Low Risk** of Diabetes based on various health parameters.

The application is built using **Python**, **Scikit-Learn**, and **Gradio**, and is deployed online using **Render**.

---

## 🚀 Live Demo

🌐 https://diabetes-predictor-3-j1jx.onrender.com

---

## 📌 Project Overview

Diabetes is one of the most common chronic diseases worldwide. Early prediction can help people seek medical advice sooner and adopt healthier lifestyles.

This project uses a trained **Decision Tree Machine Learning model** to classify whether a person is likely to have diabetes based on medical information.

Users simply enter the required health parameters using interactive sliders, and the application instantly predicts the result.

---

## ✨ Features

- 🩺 Predicts diabetes risk instantly
- 🎚️ Easy-to-use slider interface
- ⚡ Fast prediction using a trained ML model
- 🌐 Deployed online with Render
- 💻 Simple and user-friendly interface
- 📱 Accessible from any device with a web browser

---

## 📊 Input Parameters

The model uses the following medical attributes:

- Pregnancies
- Glucose Level
- Blood Pressure
- Skin Thickness
- Insulin
- BMI (Body Mass Index)
- Diabetes Pedigree Function
- Age

---

## 🤖 Machine Learning Model

**Algorithm Used:**

- Decision Tree Classifier

The trained model is saved using **Joblib** and loaded into the Gradio application for real-time predictions.
